# Виконувана модель у Camunda 8 (практикум розділу 9)

**Увага.** Файли цієї папки підготовлено за офіційною документацією Camunda 8, але в середовищі, де
створювався посібник, їх не запускали (не було Docker і Java). Команди запуску Camunda залежать від версії
платформи; перед практикумом звірте їх з актуальною документацією: https://docs.camunda.io/

## Кроки

1. Встановіть Camunda 8 Run (легкий локальний дистрибутив, потрібна Java 21) за інструкцією
   «Run Camunda 8 locally» на docs.camunda.io, або використайте пробний хмарний кластер Camunda SaaS.
2. Відкрийте models/aerocargo-tobe.bpmn у Camunda Modeler, переключіть модель на Camunda 8
   і зробіть її виконуваною: для сервісної задачі валідації (у файлі це задача бізнес-правила)
   задайте тип завдання `validate-awb` (Task definition → Type), для користувацьких задач – форми.
3. Розгорніть модель кнопкою Deploy (Camunda 8 Self-Managed, адреса кластера з документації Camunda 8 Run).
4. Запустіть виконавця: `pip install pyzeebe` і `python worker.py`.
5. Створіть екземпляр процесу (кнопка Run у Modeler або REST API, див. розділ 7.4.2 посібника)
   зі змінними, які очікує виконавець, наприклад
   `{"awb": "176-12345675", "pieces": 12, "declaredWeightKg": 412}`,
   і простежте його в Operate; користувацькі задачі виконайте в Tasklist.
